# 倒装句
完全倒装

结构：1副词+谓语+主语，2介词短语+谓语+主语，3形容词/过去分词/现在分词/介词短语+be+主语

标志：there，here，down，up，in，out，now，then，before，away，off等**副词**开头的句子，表示**强调**时（<u>主语为人称代词时，不倒装</u>）；表示地点的介词短语作状语且位于句首时；as 引导的让步状语从句，表语置于句首

部分倒装

结构：助动词/情态动词/系动词（be）+主语+实义动词/表语

标志：1，**only+副词/介词/状语从句**位于句首时（<u>only修饰主语位于句首时，不倒装</u>）；2，never，hardly，seldom，scarcely，little，not...until，at no time，not once，not，no，in no time等**否定意义**的词/词组位于句首时；3，so位于句首时，表示前句的内容也同样适用于后一个人/物时（<u>只能用于肯定句，且前后两句主语不同</u>），结构：**so +助动词+主语**，意为“主语也是如此”；4，neither/nor 位于句首，表示前句的内容也适用于后一个人/物时（<u>只能用于否定句，且前后两句主语不同</u>），结构：**neither/nor +助动词+主语**，意为“主语也不.....”



# 反义疑问句
前肯后否，前否后肯；特殊的，前面代否定词那些（seldom....），后面用肯；用否定前缀的，后面用否：

带宾语从句的，I，We开头的看从句的主语，否定转移，不是这两个开头的就不变化；祈使句的let's开头的用shall we，其余祈使句都用will you；there be句型的用are there等等；must have done的，句子表示对过去时间的推测（往往有明确时间）后面用“didn't +主语”或“wasn't + 主语”，强调动作的完成的（一般没有明确的时间），用“hasn't/haven't + 主语”；have是实义动词，完成时

- have＝有：可 haven’t，也可用 don’t

- have＝吃 / 开（会）：用 do / does / did

- have 在完成时：直接用 have / hasn’t

- have to：用 do

- had better：固定用 hadn’t you

对反义疑问句的回答，回答时，事实是肯定的用Yes加上主语和助动词或者情态动词，事实是否定的用No加上主语和助动词或者情态动词



# 感叹句
句尾有感叹号

1，感叹部分是名词性短语的，感叹词用what

考名词可数复数，不可数，what后+不加a，an多，也就是形名相连

2，感叹部分是形容词副词的，感叹句用how，以及形名不相连有a/an，“how 形容词 专有名词”



# 强调句
It is/was+被强调的部分+that/who+其他部分

只要强调部分后用that或who就好了，标志就是it开头，被强调部分可能是一个单词，词组，句子，当强调谓语动词时，在动词前加助动词“do/does/did”



# 祈使句
and连接的表示一个较好的结果

or连接的表示一个不愉快或不理想的结果
