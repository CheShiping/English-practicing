# 主谓一致
1，语法形式上的主谓一致

①amd连接两个并列名词，代词做主语时，谓语动词常用**复数**形式

②当and连接的两个并列主语共用一个冠词，且指同一类事物或同一个人身兼数职时，谓语动词用**单数**

③当两个并列连词被限定词no，every，each，many a 修饰时，尽管主语在形式上是两个，但从语义上，强调的是每个个体，谓语动词应用**单数**形式

④并列主语指成双成对的物品时，谓语动词用**单数**

⑤就近原则，1，由并列连词or，either...or，nor，neither...nor，not only...but also..等**连接两个并列主语**时，谓语动词的数应与**最近的主语保持一致**；2，在句型there be.../here be...中，谓语动词的数通常与be动词后面的主语保持一致

⑥就远原则，当句子的主语后面跟由“together with（和...一起）、with、as well as、besides、but、except、no less..than（和...一样）、including、as much as（和...一样）、rather than（而不是）”等连接的**附加成分**时，谓语动词的数不受这些附加成分的影响，而是与**距离谓语远**的主语保持**一致**

2，意义上的主谓一致

①表示时间，价格，距离，长度，重量，温度等**复数名词作主语时**，被**视为一个整体**，谓语动词用单**数**

②集体名词family，class，group，team，crew，committee，company，crowd等**作主语**时，若看做一个**整体**，谓语动词用**单数**；若看做若干个个体，谓语动词用复数，没真题例子

③一些**形式上是复数**，**意义上是单数**的名词，politics，physics，news，means，mathematics等**作主语**时，谓语动词**用单数**

④一些**形式上是单数**，**意义上是复数**的名词，people，cattle，police，public等**作主语**时，谓语动词**用复数**；定冠词**the****➕****形容词或过去分词表示一类人**，如“the old，the young，the poor，the rich，the dead，the wounded”等作主语时，谓语动词**用复数**，没真题例子

3，其他情况的主谓一致

①**动名词**，**不定式**，**主语从句作主语**时，谓语动词**用单数，**当主语为从句时，谓语动词通常用单数，但若从句内容隐含复数含义且表语为复数名词，则遵循概念一致原则使用复数动词。

②**不定词**something等作主语时，谓语动词**用单数**

③分数，百分数**修饰**名词作主语时，谓语动词的数**取决于**分数，百分数后面的**名词**

④**the** number of➕名词作主语，意为“**....的数量**”，强调总数，谓语动词**用单数**；**a** number of➕**复数**名词**主语**，意为“**许多，大量**”，谓语动词**用复数**

**主谓一致本质：**

**语义上：整体概念→单数；多个个体→复数**

**就远原则：后面是附加成分，谓语跟随前面真正主语**

**就近原则：并列主语，谓语和离它最近的主语保持一致**

# 虚拟语气
1，if型虚拟

①if虚拟条件句的**三种基本类型**

| 虚拟时态 | 从句（if） | 主句 |
| --- | --- | --- |
| 现在 | If+主语+did/were | 主语+would/should/could/might+动词原型 |
| 过去 | If+主语+had done | 主语+would/should/could/might+have+过去分词 |
| 将来 | If+主语+should/were to+do/did | 主语+would/should/could/might+动词原型 |


②错综时间虚拟条件句：“各司其职，各顾各的”

指条件从句和主句所表示的**时间不一致**的情况，所以**有很明显的时间标志**

③虚拟倒装，当虚拟条件句——if从句中含有had/were/should这三个词之一时，可以将其提到句首，同时省略if，构成倒装句式，这一规律通常被概括为“一省二提”，省if，提助动词（had/were/should）

**其本质还是三钟基本类型中从句挪个位置嘛**

④含蓄条件句，在非真实条件句中，条件从句有时并不直接出现，而是被省略，其**含义通过副词、介词短语、上下文或其他方式加以暗示**。多数情况下，条件通常隐含在介词短语中，如without...，otherwise...，but for...（要不是.....）等结构，<u>本质就是没有明确从句表虚拟了，换成翻译得有虚拟的意思，所以叫含蓄条件句嘛</u>

**题目中还是****<u>有很强的时间标志的</u>****，根据空位，在三种基本类型中对应好就好了，所以这几个词也可看成是虚拟语气的标志，说明要考虑三种基本类型从句，主句形式，空格可能出现在从句或主句位置**

2，名词性从句虚拟

①宾语从句中的虚拟，当**从句**中的**谓语**动词表示“**坚持，命令，建议，要求**”等含义时，宾语从句要用虚拟语气。包括动词（<u>insist，order，command，suggest，propose，advice，ask，demand，require，request等</u>），**宾语从句**的谓语部分由**“（should）+动词原形”**构成，其中<u>should可以省略</u>，被动关系的**“（should） be done”**

②主语从句中的虚拟，当主句表示“重要，必要，紧急，建议，要求”等含义时，主语从句要用虚拟语气，**常见结构：It is +形容词+that+主语+（should）动词**原型，常见的形容词包括“<u>necessary，important，strange，natural，advisable，anxious，compulsory，crucial，desirable，eager，essential，fitting，imperative，impossible，improper，obligatory，possible，preferable，probable，recommend，urgent，vital”，补充，“pity，requested，suggested，desired，proposed”</u>，主语从句谓语部分由**“（should）+动词原形”构成**，其中should可以省略，被动关系的“（should） be done”

③表语从句，同位语从句中的虚拟，在“<u>advice，agreement，command，decision，decree，demand，determination，indication，insistence，order，preference，proposal，request，requirement，stipulation，suggestion</u>”等名词后的表语从句，同位语从句要用虚拟语气，从句的谓语部分由**“（should）+动词原形”**构成，其中should可以省略，被动关系的“（should） be done”，没真题例子

**本质就是名词性从句中的虚拟谓语动词的意思是““坚持，命令，建议，要求，重要，必要，紧急”等意思的时候，这个谓语动词用****<u>原型</u>****或被动，有should选should，没有就是省略，变化是一样的，被动考的挺多的**

3，其他形式的虚拟

①**It's time **后的从句用虚拟语气，意为“**是时候该做某事儿了**”，It's (high/good/about/the very) time (that) sb. **did sth**；It's (high/good/about/the very) time (that) sb. **should do st**

**这个should不可省略，跟主语从句虚拟那个差不多嘛，都是should，长得也像，It's开头，真题中did的情况占多数**

_**<u>②wish，if only后的宾语从句用虚拟</u>**_

| 虚拟时态 | 从句 |
| --- | --- |
| 表示与**现在**事实相反的愿望 | did/were |
| 表示与**过去**相反的愿望 | had done |
| 表示**将来**没有把握或**不太可能实现**的愿望 | would/could do  |


**本质还是最初三种基本类型的从句变化样式**

_**<u>③以as if/as though</u>**_引导的方式状语从句或表语从句，有时用虚拟语气；<u>当as if/as though表示真实或可能的情况时用陈述语气。</u>没有真题例子

| 虚拟时态 | 从句 |
| --- | --- |
| 与**现在**事实相反 | did/were |
| 与**过去**事实相反 | had done |
| **可能性不大**或不太可能发生 | would/might/could do  |


**本质还是最初三种基本类型的从句变化样式**

_**<u>④would rather，would sooner</u>**_，would just as soon后的从句用虚拟语气，在would rather，would sooner，would just as soon后的that从句中，从句谓语习惯上用虚拟语气，表示“宁愿做什么”，<u>具体用法：1，表示现在或将来的愿望，2表示过去的愿望</u>。**本质还是三种基本类型**

**<font style="color:#117cee;background-color:#D9EAFC;">234是同基本类型从句位置保持一致，特别2的将来是同基本类型主句位置保持一致</font>**

**<font style="color:#117cee;background-color:#D9EAFC;">名词性从句以及15同should do，特别1的should不可省略</font>**

⑤lest，for fear that（以免），in case（以防）引导的目的状语从句需要用虚拟语气。从句的谓语部分由**“（should ）+动词原型”构成**，should可省略

**本质就两种，1，三种基本类型，2，should do，should be done，should可省略；这就是虚拟语气所有情况都离不开的本质**

# 非谓语
#### 不定式
**做成分**，①作主语，注意头重脚轻，可能出现it做形式主语；②作宾语，一些**及物动词后**加to do作宾语，**介词只有but，except**后面加to do作宾语；③作表语，有do省to；④作定语，最高级和序数词后加to do作后置定语；⑤作状语，in order to，only to...，too 

...to...，结果状语，**出乎意料的结果**；⑥作补语，宾补主动省to，主补被动还原

**形式**，<u>to do，to be done，to have done，to have been done，to be doing，to have been doing</u>，具体是主动还是被动，发生在谓语动词之前，之中，还是之后，**这些本质才是重点**

逻辑主语，for（外在的） sb.，of（内在的） sb.

否定，前面加not

#### 动名词
**做成分**，①作主语，也是头重脚轻，it作形式主语，但出现的**少**，只有**在很确定的句型中**（It's no use/a waste of time doing sth.）；②作宾语，有一些及物动词后面固定加doing，这就**要和加to do的分开，这就是重点**；介词后面基本上就是doing作宾语，<u>特别注意in，to后面加doing的情况</u>（accustomed to doing）；

**形式**，doing，being done，having done，having been done，是主动还是被动，发生在谓语动作之前还是一般状况，**这些本质才是重点**

**逻辑主语**，行物代或所有格，宾格，普通格（无生命的，较长的名词词组，其他代词）

否定，前面加not

- be engaged (in) doing sth. 忙于做某事

- have fun (in) doing sth. 做某事很开心

- be busy (in) doing sth. 忙于做某事

- there is no point (in) doing sth. 做某事没意义

- spend time (in) doing sth. 花费时间做某事

- have difficulty (in) doing sth. 做某事有困难

- have a good/great time (in) doing sth. 做某事开心

#### 分词
**做成分**，作定状补，关注不做成分的类型，作定语知道哪些不做定语，作状语知道哪些不做状语，作补语知道哪些不做补语，直接先排除，再注意前置定语和后置定语的问题，作状语注意逻辑主语是否一致

**形式**，doing，being done，having done，having been done，vt. done，vi. done，前四种和动名词一致

逻辑主语，独立主格结构的问题，或一致的时候被省略了

否定，前面加not

<u>would rather 加原形，than 后面也原形</u>

**大总结**

| | 主动 | 被动 |
| --- | --- | --- |
| 不确定 | to do<br/>to be doing<br/>to have done<br/>to have been doing | to be done<br/>to have been done |
| 确定 | doing<br/>having done<br/>vi. done | being done<br/>having been done<br/>vt. done |

 1．确定考点：查看句子是否缺少谓语动词，以判断是否使用非谓语动词。 （一般情况下，同一个句子不能出现两个谓语，如果句子有谓语则选择非谓语）） 2．找逻辑主语：一般为非谓语前面的名词或代词（独立主格），如果非谓 语前面没有名词或代词，则逻辑主语为句子主语。 3．判断逻辑关系：判断逻辑主语和非谓语之间的逻辑关系，决定非谓语 是用主动形式还是被动形式。 （1）与逻辑主语之间为主动逻辑关系，用现在分词v.-ing（**逻辑主 语是人，多选主动**） （2）与逻辑主语之间为被动逻辑关系，用过去分词v.-ed（**逻辑主 语是物，多选被动**） （3）表目的或打算用不定式to do 4．判断时态：根据动作的先后关系等，判断应该使用的时态。 分词动作与主句动作同时发生→v.-ing（现在分词） 分词动作先于主句动作发生→having done  

:::

# 情态动词
推测和虚拟

can，①表达能力，能，会②表示请求或许可，可以，can we...③表示猜测，可能；can't不可能

may，①用于疑问句，表示请求或允许，可以，准许②推测，表示可能性，可能，也许

might是may的过去式，可以代替may，但语气较为婉转或更加不肯定

must，①表示义务，必要或命令，必须，应该②表示肯定推测，肯定，一定；must引起的一般疑问句，肯定回答要用must，否定回答要用needn't或don't have to ，而不用mustn't 表示“禁止，不许”；否定mustn't表示进制禁止

need，需要，有必要，needn't，没必要，不需要

shall，①表示命令，许诺，警告，强制，威胁，决心等含义时，一般用于第二第三人称的陈述句中，②用于征求对方的意见或指示时，用在第一，第三人称的疑问句中

had better，最好，表示建议，忠告，建议某人，最好不要做某事，had better not do sth

否定句表推测，may not/ might not  可能不

can not / could not   不可能

回答：can/could    肯定回答can；否定回答can't；

must       肯定回答must，否定回答needn't/don't have to ；

need        同must回答；

may        肯定回答 can/may，否定回答can't/mustn't

情态动词加have done表推测

can用于否定句，疑问句；must仅用于肯定句

must have done  一定做过某事

情态动词加have done表虚拟语气

表示与事实相反，一般译为“本...（事实却不这样）”，否定形式直接加not，译为“不...（与事实相反）”

might have done  过去本可能做（但实际没做）

should have done 本应该做但未做

would have done   本来会做但没做

could have done   本来可以做而未做

needn't have done   本没必要做...但做了
